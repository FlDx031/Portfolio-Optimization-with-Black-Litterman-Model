## Points d’attention
- Le backtest est `monthly` walk‑forward par défaut (`TRAIN_WINDOW_MONTHS = 36`). Modifiez la configuration au début de `BacktestBL.py` si besoin.
- `yfinance` / `pandas_datareader` (FRED) peuvent retourner timeouts ou données manquantes; le code inclut des fallbacks raisonnables.
- `BRK.B` doit être fourni sous forme `BRK-B` si utilisé (format yfinance).
